# L'argumentation

## Objectif

Identifier une thèse, les arguments employés et les exemples qui les illustrent.

## Vocabulaire

- **Thèse** : idée principale défendue par l'auteur.
- **Argument** : raisonnement utilisé pour soutenir la thèse.
- **Exemple** : situation concrète qui illustre un argument.

Ce document est une ressource locale de démonstration modifiable depuis SIOManager.
